# Cambios

## 1.0.0 · 2026-10-06
- Primera versión pública.
- Una sola skill para todas las empresas; cada empresa es una carpeta con su configuración.
- Canales combinables: página en claude.ai (`artifact`), página estática (`html`), correo, o solo notas.
- Página «Mis inversiones» con estilo de notas de versión, tema claro/oscuro, tamaño de letra y simulador de precio.
- Correo para Gmail con modo solo correo.
- Alta guiada que pregunta solo lo que falta y se puede retomar.
- Scripts en Python estándar: `validar.py`, `build_page.py`, `render_email.py`.
- Compatible con el formato Agent Skills (Claude, Codex, Cursor, Gemini CLI, Copilot…), más `AGENTS.md`.
